01
Como o sistema funciona

Quando uma reserva entra — pelo Airbnb, Booking ou site direto — o sistema detecta automaticamente e gera um link exclusivo para aquela estadia. Esse link é o centro de tudo: é onde o hóspede cadastra os documentos e, depois de aprovado, é onde ele encontra todas as informações para o check-in.

📋
Reserva entra
Airbnb, Booking ou site direto
🔗
Link gerado
Um por reserva, automático
📱
Hóspede recebe
WhatsApp ou chat Airbnb
📄
Preenche docs
Pelo link, antes das 20h
🏠
Recebe acesso
Endereço, senha, Wi-Fi

Reservas do site direto e Booking recebem o link automaticamente por WhatsApp. Reservas do Airbnb recebem pelo chat interno da plataforma — você configura uma mensagem automática no Airbnb com o link embutido (veja a seção 4).

03
Painel da equipe

O painel é onde a equipe acompanha e opera as reservas. Há três áreas principais:

📋 Painel de Reservas
zainalofts7.alojadoanfitriao.com.br/painel

Lista os check-ins dos próximos 15 dias (editável). Mostra status do onboarding e se a senha da porta foi preenchida. Use a busca para localizar qualquer reserva pelo código interno (ex: OB14J) ou código Airbnb. Clique em qualquer linha para abrir a reserva.

🏠 Detalhes da Reserva
zainalofts7.alojadoanfitriao.com.br/admin/{token}

Mostra todos os dados: hóspede, documentos enviados, dados da unidade e regras da casa. Os únicos campos editáveis aqui são Senha da porta e Observações de acesso — ambos aparecem para o hóspede assim que salvos.

⚙️ Unidades
zainalofts7.alojadoanfitriao.com.br/painel/unidades

Edite os dados fixos de cada unidade: nome da rede Wi-Fi, senha do Wi-Fi e método de acesso. Esses dados aparecem automaticamente na jornada de todos os hóspedes daquela unidade.

O acesso ao painel é protegido por PIN. Use Leo@zl7 para entrar. Qualquer alteração feita no painel aparece imediatamente na página do hóspede — sem precisar recarregar.
04
Inserindo a senha da porta

Este é o passo mais importante da operação diária. Quando o hóspede conclui o cadastro, a equipe precisa inserir a senha gerada pelo EasyLock/TTLock para aquela reserva.

1
Abra o Painel de Reservas
Veja as reservas com onboarding preenchido (badge verde) e sem senha (vermelho "Sem senha"). Essas são as que precisam de ação.
2
Clique na reserva
Abre a página de detalhes. Role até a seção "Dados para o hóspede — editar".
3
Digite a senha e salve
Insira a senha gerada pelo EasyLock no campo "Senha da porta". Clique em "Salvar alterações". A senha aparece imediatamente na página do hóspede.
4
Confirme na página do hóspede
Para confirmar, abra o link do hóspede (disponível na coluna "Onboarding" do painel) e verifique se a senha aparece corretamente.
05
Enviando o link pelo Airbnb
⚠️ Ainda não faça isso. O sistema está em fase de testes. Esta seção é uma referência para quando o piloto for aprovado — por ora, nenhuma mensagem automática precisa ser configurada no Airbnb.

Para reservas do Airbnb, o link de onboarding precisa ser enviado pelo chat interno da plataforma. O jeito mais simples é usar as mensagens agendadas do próprio Airbnb — você configura uma vez e ela dispara automaticamente para cada reserva nova.

O texto abaixo é uma sugestão de referência. Você pode adaptar livremente, inclusive aproveitando uma mensagem automática que já usa — o que importa é que o link esteja presente com a variável correta do código de reserva.

Onde configurar: Airbnb → Anúncios → Ferramentas → Mensagens agendadas → Nova mensagem

Quando disparar: após confirmação da reserva

Variável do Airbnb para o código de reserva: {{ reservation.confirmation_code }}

O único elemento obrigatório na mensagem é o link com a variável como token — assim cada hóspede recebe o link certo para a sua reserva:

Olá, {{ first_name }}! Sua reserva na Zainalofts7 está confirmada. 🙏 Para liberar seu acesso ao prédio, precisamos do cadastro dos hóspedes. Acesse pelo link abaixo — leva menos de 2 minutos: 👉 https://zainalofts7.alojadoanfitriao.com.br/reserva/{{ reservation.confirmation_code }} Preencha até às 20h do dia do check-in. Após o cadastro, você verá no mesmo link: endereço, senha e Wi-Fi. "Que tudo seja feito com amor." — Equipe Zainalofts7 🏠
Para reservas do site e Booking, o WhatsApp dispara o link automaticamente — sem precisar configurar nada no Airbnb.
